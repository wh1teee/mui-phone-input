This is the **stable 1.0.4 patch release** of
`@wh1teee/mui-phone-input`. It preserves the stable renderer and metadata
architecture while correcting immediate desktop click-away dismissal in WebKit.

## Correction

- Desktop Country Selector dismissal now uses an owned document listener and an
  internal surface wrapper instead of the timer-armed Material UI
  `ClickAwayListener`.
- A custom popup slot may ignore its forwarded `ref` without disabling outside
  click dismissal. Containment still recognizes the trigger, inline and portaled
  popup surfaces, and composed event paths.
- The opening click is not reprocessed, inside interactions remain intact, and
  outside clicks close without restoring focus unexpectedly.

The existing regression that renders a plain popup slot without a ref now passes
in Chromium, Firefox and WebKit. The source WCAG visual harness and the complete
browser suite remain release gates.

## Stable architecture retained

- MUI, headless, Base UI and shadcn remain independent renderer graphs.
- React Hook Form adapters remain explicit renderer subpaths.
- Default paths use max metadata; `/min` paths use the smaller official min metadata. The mobile and validated custom metadata presets remain available as explicit neutral exports.
- Entrypoint bundle budgets include Maskito, `libphonenumber-js`, `tabbable` and
  selected metadata while excluding application-owned React/UI peers.
- Next.js 16 App Router and Vite exact-tarball consumers require no
  `transpilePackages`, `serverExternalPackages`, or experimental
  `optimizePackageImports` configuration.

The release is published through npm OIDC with immutable exact-artifact,
provenance, SBOM, registry-byte-parity, latest/minimum peer, WCAG and browser
verification.

Physical-device and assistive-technology evidence remains explicitly
`NOT_AVAILABLE`; the owner-accepted residual is recorded in `mpi-oan.24`.
Fresh exact-artifact RideOS validation came from merged RideOS PR #442. The
deferred Christofle item `mpi-oan.19` is unchanged. Stable patch publication and
npm `latest` promotion were explicitly authorized by the package owner on
2026-09-21.

The supported metadata preset family is explicitly: max, min, mobile and validated custom metadata.
