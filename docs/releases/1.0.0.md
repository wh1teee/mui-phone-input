This is the **stable 1.0 release** of `@wh1teee/mui-phone-input`. The public
phone value, transaction, country-selection, validation, extension, metadata,
locale, flag, MUI, headless, Base UI/shadcn, React Hook Form, Zod and neutral
server contracts are frozen under SemVer.

## Renderer and bundle architecture

- The package root and `/mui` expose the Material UI renderer. `/headless`,
  `/base-ui`, and `/shadcn` are independent graphs; importing one renderer never
  installs or bundles the other renderer's optional peers.
- `/shadcn.css` remains explicit and side-effect-scoped. It contains no global
  reset or implicit Tailwind requirement.
- Every browser renderer has a `/min` entrypoint. Default paths use max metadata
  for strict validation/type precision; `/min` paths use official
  `metadata.min.json` for formatting and possible-number oriented products.
- Entrypoint bundle budgets include Maskito, `libphonenumber-js`, `tabbable`,
  and selected metadata. Current `/min` closures save about 21–22 KiB gzip over
  their max counterparts. Exact-artifact CI rejects budget regression,
  metadata mixing, and cross-renderer leakage.
- React Hook Form adapters are available through explicit renderer paths,
  including `/mui/react-hook-form`, `/base-ui/react-hook-form`, and their `/min`
  equivalents. Zod and `/server` remain neutral.

## Next.js and package consumption

The exact tarball is installed into production Next.js 16 App Router and Vite
consumers. Package-owned UI entrypoints retain their `use client` boundary;
`/server` remains browser/UI-free. The Next.js proof requires no
`transpilePackages`, `serverExternalPackages`, or experimental
`optimizePackageImports` configuration.

## Release evidence and accepted residuals

The release uses the same immutable npm OIDC/provenance workflow as the
prerelease line. Exact tarball declarations, SSR/hydration, latest/minimum peer
matrices, Chromium/Firefox/WebKit interaction suites, WCAG 2.2 automated and
visual gates, metadata freshness, source maps, licenses/notices, SBOM and
registry byte parity remain release requirements.

Physical-device and assistive-technology evidence remains explicitly
`NOT_AVAILABLE`, not silently promoted to PASS. That owner-accepted residual is
recorded in `mpi-oan.24`. Fresh exact-artifact RideOS validation is represented
by merged RideOS PR #442. PayAtTable independently consumes the headless/Base UI
customer graph and the MUI/operator family. The historical Christofle adoption
item `mpi-oan.19` remains explicitly deferred and was not accessed or modified
for this release.

Stable 1.0 publication and npm `latest` promotion were explicitly authorized by
the package owner on 2026-09-21.

React Hook Form, max, min, mobile and custom metadata remain independently
available. Live task state and exact release receipts remain in Beads/Dolt.
