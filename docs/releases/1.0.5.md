This is the **stable 1.0.5 patch release** of
`@wh1teee/mui-phone-input`. Runtime behavior and public declarations are
unchanged from 1.0.4; the repository and exact consumer matrix now use the
stable native TypeScript 7 compiler.

## TypeScript 7 toolchain

- `tsc` is TypeScript `7.0.2`, the native Go-based compiler.
- tsdown, documentation syntax checks, and package-boundary tools that still
  embed TypeScript's JavaScript programmatic API receive Microsoft's official
  `@typescript/typescript6@6.0.2` compatibility package through an npm alias.
- The compatibility package does not own application type-checking. CI verifies
  that the root package, library workspace, docs, Next.js consumer, Vite
  consumer, and isolated packed consumers all resolve `tsc` to 7.0.2.
- The exact package remains ESM-only and keeps the same MUI, headless, Base UI,
  shadcn, min-metadata, server, RHF, Zod, locale and flag entrypoint boundaries.

This dual-toolchain topology follows the TypeScript team's production guidance
while TypeScript 7's programmatic API remains unstable. It avoids pinning the
actual compiler to TypeScript 6 merely for tools that inspect syntax or emit
declarations.

All existing exact-artifact package, declaration, renderer-isolation,
Next.js 16 App Router, Vite, Chromium/Firefox/WebKit, WCAG 2.2, bundle budget,
metadata freshness, SBOM, provenance and registry-byte-parity gates remain
required for publication.

Physical-device and assistive-technology evidence remains explicitly
`NOT_AVAILABLE`, as previously owner-accepted and recorded in `mpi-oan.24`.
The deferred Christofle item `mpi-oan.19` remains unchanged.

## Stable 1.0 compatibility retained

The stable 1.0 API remains unchanged: React Hook Form (RHF), Zod, server,
locale, flag, and renderer-specific exports retain their existing contracts.
The supported metadata preset family remains **max, min, mobile, and validated
custom metadata**. Default paths retain max metadata; `/min` paths retain their
explicit `metadata.min.json` authority and entrypoint bundle budgets.

The exact package continues to pass the production Next.js 16 App Router and
Vite consumers without package-specific transpilation or server-externalization.
The fresh exact-artifact RideOS validation remains the previously merged RideOS
PR #442 evidence; this toolchain-only patch does not change runtime bytes.
