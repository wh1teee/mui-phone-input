Let products put the country list in their own sheet, choose what the trigger shows, follow a late default country and search countries in Japanese.

- Base UI/shadcn export `PhoneCountryTrigger` and `PhoneCountryList`, the two parts the built-in popover is now made of. Put the list in your own dialog or bottom sheet (it owns drag, focus trap and back gesture) and close it from `onSelect(country)`, which runs after the selection is applied. The list is named by `messages.dialogTitle`, owns its keyboard model, marks and scrolls to the selected row, and mirrors `aria-activedescendant` when focused itself. `autoFocusSearch` (`true`, `false` or `'fine-pointer'`) keeps the on-screen keyboard closed on touch devices. Both parts use the `locale` and `messages` given to `usePhoneInput` (new `messages` option; `phone.state` gains `locale` and `messages`) unless their own props say otherwise.
- Base UI/shadcn `PhoneInput` gains `renderCountrySelector`, which replaces only the country presentation (for example a host sheet on phones and the built-in popover on wide screens) and receives `phone`, `triggerProps`, `listProps`, `defaultSelector` and `onSelect`.
- `triggerContent` (`'auto'`, `'calling-code'`, `'country-code'`, `'both'` or a render function) on both renderers. `'calling-code'` draws `+375` in national mode; in international modes, where the input already starts with the code, it falls back to `'auto'`. `'auto'` keeps the current rendering.
- Behaviour change, Base UI/shadcn: the country trigger's accessible name now always contains the selected country and calling code through the new optional `triggerLabel` message present in every locale. Without a host label it was "Select country" and is now "Select country. Belarus, BY, +375", like the MUI trigger. A host `triggerProps['aria-label']` used to replace the name and is now its prefix ("Country. Belarus, BY, +375"). MUI is unchanged: its default name already carried the selection, and a host `aria-label` is still the whole name.
- While a field is untouched (empty, never edited, nothing picked), the selected country follows a changed `defaultCountry`, reported by `onCountryChange` with reason `default`. A late value that is missing, empty or not a country of the loaded metadata is ignored, as before.
- Add the Japanese locale, `@wh1teee/mui-phone-input/locales/ja`, with `searchAliases`: kana readings of every country name written with kanji. A new `searchAliases` option of the country list accepts them. Search now folds hiragana to katakana, so `べらるーし`, `にほん` and `+８１` find their countries before IME conversion.
- `shadcn.css` lets off-screen option rows skip layout and paint (`content-visibility: auto` with a single-line row height as intrinsic size), so the full list opens cheaper; option rows use `box-sizing: border-box`.

Entry sizes stay within budget (gzip): `/base-ui` and `/shadcn` +1.7 KB (85.5 → 87.2 KB), `/base-ui/min` and `/shadcn/min` +1.7 KB (64.3 → 66.0 KB, 9 B under the limit), `/mui` +0.5 KB, `/headless` +0.2 KB. The MUI main closure budget moves from 33,506 to 34,023 bytes gzip (measured +517 B, 96 B headroom kept).
